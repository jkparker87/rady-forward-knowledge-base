# Metric definitions

A metric page is the organizational contract for what a number means.

Every metric should define:

- the question it is intended to answer
- the eligible population
- numerator and denominator, where applicable
- date / time basis
- inclusion and exclusion rules
- recommended dimensions
- common misinterpretations
- related curated assets

A metric definition should be understandable before a reader sees SQL.
