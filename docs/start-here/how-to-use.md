# How to Use This Site

Use Rady Forward when you need **context, standards, workflow guidance, or an explanation of how systems and practices fit together**.

## Start with your question

### “How do I do this work?”
Start in **How We Work** or **Standards & Playbooks**.

### “What does this data mean?”
Start here for context, then follow links to the enterprise data catalog when the canonical definition, owner, certification status, or lineage is needed.

### “Where is the code?”
Use the relevant page to understand the purpose and then follow the implementation link to GitHub.

### “Where does the data live?”
Use **Systems & Data Flows** for orientation. Use the data platform and catalog for technical object-level detail.

### “How should this product work for users?”
Start in **Product Design**.

### “How do I learn this?”
Start in **Learning**.

## Audience levels

Pages should make their intended audience clear. Common audiences include:

- enterprise leaders and operational users
- data consumers
- analysts and data practitioners
- data engineers and developers
- product owners
- governance and standards groups

Technical implementation detail should not dominate pages intended for broad audiences.
