# Guides & analytical patterns

These pages explain recurring reasoning patterns that apply across domains.

Use them when you need to decide:

- what one row should represent
- how tables can be joined safely
- which date belongs in a metric
- how to construct a denominator
- how null, zero, and unknown differ
- whether a problem should be modeled as events or snapshots
- how historical changes affect interpretation

The **question-to-data pathways** apply those patterns to common business questions.
