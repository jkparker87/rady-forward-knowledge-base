# GitHub Copilot Workgroup

## Purpose

Define appropriate use of GitHub Copilot for analytics development and create the tools, structures, standards, and guidance required for consistent AI-assisted work.

## Primary goals

1. Define appropriate use of Copilot.
2. Build enabling tools and structures.
3. Support adoption and continuous improvement.

## Typical deliverables

- usage standards
- reusable prompts, agents, skills, and instructions
- contextual documentation
- training and onboarding
- review and validation guidance

## Boundary

The workgroup should enable analytics development rather than replace core data platforms, governance ownership, or downstream operational processes.
