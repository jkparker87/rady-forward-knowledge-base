# Ownership and stewardship

Use role-based ownership rather than relying on one person to own every aspect of a data concept.

| Responsibility | Typical owner |
| --- | --- |
| Business meaning | Operational / clinical domain owner |
| Definition stewardship | Data steward or designated subject-matter expert |
| Technical implementation | Analytics / data engineering |
| Quality monitoring | Shared between steward and technical owner |
| Documentation maintenance | Named maintainer with review cadence |

Ownership metadata should usually identify roles or durable teams rather than individuals when possible. Individual names change more often than responsibilities.
