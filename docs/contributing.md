# Contribute

Rady Forward is maintained through Markdown and GitHub.

## Standard workflow

1. Create or update a Markdown page.
2. Use the appropriate template and page metadata.
3. Preview locally with `mkdocs serve`.
4. Create a pull request.
5. Allow automated checks to run.
6. Request review from the appropriate owner or subject-matter expert.
7. Merge after approval.
8. GitHub Actions publishes the updated site.

## Writing principles

- Write for the intended audience.
- Put the answer before the implementation detail.
- Link to authoritative systems rather than copying them.
- State assumptions and limitations.
- Avoid unexplained acronyms.
- Use diagrams when they clarify relationships or workflows.
- Keep headings descriptive and searchable.
- Remove stale content rather than letting contradictory guidance accumulate.

## Adding a new page

Follow [Publishing a New Document](how-we-work/publishing-a-new-document.md) for the complete authoring, preview, review, and publication workflow.
