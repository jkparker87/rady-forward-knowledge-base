# Responsible AI

Responsible AI guidance should make safe behavior the default without making the workflow unnecessarily difficult.

## Baseline principles

- Human accountability remains with the person using the output.
- AI-generated code and analysis require appropriate validation.
- Sensitive data should only be used in approved tools and approved ways.
- AI should not invent business definitions, lineage, or governance decisions.
- Existing standards take precedence over generated suggestions.
- Important analytical assumptions should be explicit and reviewable.
- Reusable AI assets should be version controlled and governed.

## Validation by task type

| Task | Minimum expectation |
|---|---|
| Code generation | Syntax, logic, performance, style, and output validation |
| Analysis | Method appropriateness, assumptions, data quality, interpretation |
| Documentation | Source verification, ownership, link accuracy |
| Metadata | Confirm against authoritative catalog/source |
| Automation | Test failure modes, permissions, and unintended side effects |
