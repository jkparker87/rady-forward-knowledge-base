# AI & Automation

AI should reduce friction in repeatable work while preserving clear accountability for decisions, validation, and governance.

## This section should cover

- approved use cases
- responsible-use principles
- GitHub Copilot workflows
- reusable prompts, agents, and skills at a conceptual level
- automation patterns
- review and validation expectations
- links to the technical implementation

## Design principle

> Put **how to use the capability** in the knowledge hub and **how the capability is implemented** in the code repository.
