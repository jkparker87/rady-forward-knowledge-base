# Standards & Playbooks

Standards reduce unnecessary variation without eliminating professional judgment.

The goal is not to force every analytical problem into the same method. The goal is to make **repeatable parts of the work consistent**, so practitioners can focus their judgment on the parts that actually require it.

## Standards currently represented

- SQL style and development practices
- analytics methods and reusable analytical workflows
- data-quality assessment
- documentation expectations

## What makes a good standard

A useful standard should explain:

1. **Purpose** — what problem the standard addresses.
2. **Scope** — where it applies.
3. **Required practices** — what is non-negotiable.
4. **Recommended practices** — where judgment is appropriate.
5. **Examples** — what good implementation looks like.
6. **Ownership** — who maintains it.
7. **Review process** — how it changes over time.
